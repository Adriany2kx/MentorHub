# MentorHub Design Context

## Users

**Primary:** Career-driven professionals (engineers, PMs, designers, founders) seeking 1:1 mentorship to reach their next role, raise, or launch.

**Context:** Users arrive stressed about career progression, often feeling stuck. They need clarity, not complexity. Most interactions happen on desktop during work hours or evenings.

**Job to be done:** Find a qualified mentor who has walked my path, book a session, and get actionable guidance that moves my career forward.

---

## Brand Personality

**Voice:** Calm, Focused, Minimal

**Tone:**
- Reassuring, not salesy
- Direct, not verbose
- Warm, not cold or corporate
- Confident, not boastful

**Emotional goals:** Users should feel:
- Calm when browsing (not overwhelmed by choices)
- Confident when booking (this is the right mentor for me)
- Supported throughout (I'm not alone in this)

## Design Principles

### 1. Calm over clever
Remove visual noise. Every element must earn its place. When in doubt, remove it.

### 2. Guide, don't overwhelm
Progressive disclosure. Show only what's needed at each step. First-time users get contextual hints; returning users get a clean slate.

### 3. Typography is the interface
Headlines do heavy lifting. Body copy is scannable. Spacing creates rhythm. Cards are containers, not decoration.

### 4. Warm, not cold
Cream backgrounds, soft shadows, rounded corners. The interface should feel like a trusted advisor's office, not a tech startup's dashboard.

### 5. Accessibility is non-negotiable
WCAG AA compliance minimum. 4.5:1 contrast ratios. Keyboard navigable. Focus indicators visible. Reduced motion respected.

## Technical Constraints

- React 19 + TypeScript + Tailwind CSS 4
- Radix UI primitives for accessible components
- Lucide icons (consistent 24px stroke)
- No dark mode (warm paper aesthetic is core)
- Mobile-responsive but desktop-first
- `prefers-reduced-motion` respected for all animations

## Animation Principles

### Timing
- **Fast interactions:** 100-150ms (hovers, clicks, focus)
- **Normal transitions:** 200-250ms (modals, dropdowns)
- **Entrance animations:** 300-400ms (page loads, reveals)
- **Exit animations:** 150-200ms (always faster than enter)

### Easing
```css
--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);    /* Primary enter */
--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);   /* Secondary enter */
--spring: cubic-bezier(0.34, 1.56, 0.64, 1);       /* Playful bounce */
--ease-in: cubic-bezier(0.4, 0, 1, 1);             /* Exit animations */
```

### Patterns
| Interaction | Animation |
|-------------|-----------|
| Page enter | Fade up (24px) over 650ms |
| Modal open | Scale 0.95→1.0 + backdrop blur |
| Card hover | Lift 2-4px + shadow increase |
| Button click | Scale 0.98 snap |
| Number change | Count up / slot machine |
| Icon hover | Scale 1.1 + slight rotation |
| Success | Checkmark draw + color flash |
| Error | Shake (3 oscillations) |

### Rules
1. **Purpose over polish** — every animation must aid understanding
2. **Respect user preferences** — always check `prefers-reduced-motion`
3. **60fps or nothing** — use `transform` and `opacity` only
4. **Subtle is better** — if you notice the animation, it's too much
5. **Consistent timing** — same interaction = same duration everywhere

## Landing Page Specifics

The landing page should:
- Lead with value proposition, not product features
- Use Newsreader serif for the hero headline (2-3 lines max)
- Show social proof early (mentor count, rating, company logos)
- Provide a clear path: Browse > Book > Grow
- Avoid dark mode — maintain warm paper aesthetic
- Include subtle animations (fade-up on scroll) but no parallax or heavy motion

---

## Page-Specific Guidelines

### Auth Pages (Login, Register)
- Single centered card on warm paper background
- Password reveal animation (eye morph)
- Social login buttons with subtle hover lift
- Error states: shake + red border flash
- Success: redirect with fade transition

### Dashboard (Mentee/Mentor)
- Welcome banner with user's first name
- Key stats with animated numbers
- Upcoming sessions card (max 3 visible)
- Quick actions grid (2x2 on mobile, 4-col on desktop)
- Achievement badge showcase (horizontal scroll on mobile)

### Mentor Directory
- Hero with search + suggested skills
- Filter sidebar (frosted glass on mobile)
- Editorial mentor cards (4:3 aspect photo area)
- Hover: card lifts, photo zooms, bio reveals
- Skeleton loading with shimmer

### Booking Flow
- Step indicator (1. Select → 2. Confirm → 3. Pay)
- Calendar with animated date selection
- Stripe Elements with loading states
- Success: confetti burst + calendar add buttons

### Messages
- Conversation list with unread indicators
- Pull-to-refresh on mobile
- Message bubbles with send animation
- Typing indicator with bouncing dots
- Real-time updates (WebSocket)

### Goals & Progress
- Compact goal cards with progress rings
- Milestone checkboxes with pop animation
- Completion celebration (confetti + banner)
- Timeline view with staggered reveal

### Admin Dashboard
- Toggle: Simple (4 stats) vs Advanced (charts + tables)
- Revenue cards with animated number transitions
- User management table with bulk actions
- Frosted filter menu
- Tax/payout calculations section
